# منظف الجوال (PhoneCleaner)

تطبيق أندرويد (Kotlin + Compose) يفحص التخزين ويقترح ملفات يمكن حذفها.

## البناء
- عبر GitHub Actions: يُنتج `app-debug.apk` في Artifacts.
- محليًا: افتح المشروع في Android Studio (يولّد Gradle wrapper تلقائيًا)، أو نفّذ مرة واحدة
  `gradle wrapper --gradle-version 8.9` ثم `./gradlew assembleDebug`.

## قواعد الأمان
- لا يُحدَّد تلقائيًا إلا: ملفات مؤقتة/سجلات، كاش التطبيق نفسه، مجلدات فارغة.
- المكررات والنسخ الاحتياطية وAPK والتنزيلات القديمة والملفات الكبيرة تحتاج تحديدًا يدويًا.
- ملفات المستخدم تُنقل إلى سلة التطبيق (30 يومًا) ويمكن استعادتها؛ السلة تُحذف مع إزالة التطبيق.
- لا تُلمس `Android/` ولا المجلدات المخفية ولا ملفات `.nomedia` ولا المجلدات القياسية (DCIM، Download…).
- قبل كل حذف يُتحقق أن الملف لم يتغير منذ الفحص، وأن النسخة المحفوظة من المكرر ما زالت سليمة.

## ملاحظة
إذن `MANAGE_EXTERNAL_STORAGE` غير مقبول عادةً في Google Play؛ التطبيق مناسب للتوزيع المباشر.
